# SRE Job Preparation (5+ Years Experience)

A structured, self-paced study repository for preparing for **Senior Site Reliability Engineer** interviews.
Target profile: 5+ years experience, Azure / Kubernetes / Azure DevOps focused.

## How to use this repo

1. Start with [study-plan/8-week-plan.md](study-plan/8-week-plan.md).
2. Work through modules `01` → `11` in order. Each module has:
   - **Concepts** — what to know cold.
   - **Commands / Cheatsheet** — muscle memory.
   - **Interview questions** — with model answers.
3. Do the hands-on exercises in [12-labs](12-labs/README.md). Interviews at senior level are practical.
4. Track progress in [study-plan/progress-tracker.md](study-plan/progress-tracker.md).

## Interview loop you should expect (senior SRE)

1. Recruiter screen — motivation, comp, scope.
2. Technical screen — Linux/K8s troubleshooting, coding (easy/medium).
3. Coding — scripting/automation, log parsing, API work.
4. Systems / Troubleshooting — "the site is down, debug it".
5. System design — design a reliable, scalable service.
6. SRE practices — SLOs, on-call, incident/postmortem culture.
7. Behavioral / leadership — influence, conflict, mentoring.
8. Hiring manager — scope, ownership, roadmap thinking.
