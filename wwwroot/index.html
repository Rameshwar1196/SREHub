    PowerShell

    A persistent shell on the machine running SRE Hub. Variables, the current folder and az login carry over between commands. Press Enter to run, Shift+Enter for a new line, Up/Down for history, Ctrl+C to stop.

    - Idle
    PS>

    Commands run with the permissions of the account hosting SRE Hub and are recorded in an audit log. Interactive prompts are not supported; pass parameters explicitly.
